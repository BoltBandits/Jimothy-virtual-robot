# Your folder

Put **your own** OpModes here. Everything in this folder is ignored by git, so

- `git pull` will never overwrite your work or stop with a conflict, and
- new BioBuzz Lab lessons arrive cleanly whenever you pull.

Start each file in this folder with:

```java
package org.firstinspires.ftc.teamcode.student;
```

The simulator scans every package, so your OpMode still shows up in the
dropdown. To start from a lesson's starter file, copy it out of
`biobuzz-lab/lessonN/starter-code/` into here and change the `package` line
to the one above.
